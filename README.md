# agent-sandbox

Throwaway practice repo for Autonomous Agent. Safe to break.

A tiny Python calculator library.

## Run the tests
```bash
pip install pytest
pytest -q
```

## React app
`calculator/` is a React (Vite + TypeScript) port of the library with a small UI.
```bash
cd calculator && npm install
npm run dev    # dev server
npm test       # unit tests
```
